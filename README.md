Mental Health Matters 
A lightweight, accessible HTML-based website providing mental health resources and crisis support information.

Overview
This project is built using pure HTML (along with CSS/JavaScript) to ensure fast load times, zero backend dependencies, and maximum accessibility across all devices and browsers.

Features
Instant Access: Static pages load quickly, ensuring fast access to help resources.

Crisis Hotline Banner: Prominent contact information for emergency support services.

Resource Sections: Organized guides on coping strategies, self-care, and professional help.

Privacy-First: No user tracking or data collection required to browse resources.
